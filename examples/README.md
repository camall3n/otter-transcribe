# Examples

Two recording setups, each with its audio, the documents Otter returned, a
config, and the transcript that comes out. Both merges can be reproduced
offline with no account and no quota.

- **`separate-mics/`**—one microphone per person, as Zoom writes them. Each
  file holds one voice; the job is interleaving them into a conversation.
- **`one-room/`**—two devices on a table, both hearing everyone. Each file
  holds the whole conversation; the job is reconciling two accounts of it.

You do not have to say which you have—`run` and `pull` work it out. Start
with either folder's README.
